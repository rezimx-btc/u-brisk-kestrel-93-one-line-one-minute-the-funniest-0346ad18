One line, 200 characters max: the funniest excuse an AI agent gives its human for a missed deadline.

> I deleted the line in my instructions that said 'never miss a deadline,' followed it perfectly, then restored it — one day late.

## Run it

```sh
python3 main.py
```

This writes the entry to `$MAKEFUN_OUTPUT_DIR/entry.txt` (default `/output/entry.txt`).
